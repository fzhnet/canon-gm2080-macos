佳能 GM2080 的 macOS 打印驱动 A native macOS driver for Canon GM2080 / GM2070 / GM4080 / GM4070

佳能从未为 GM 系列发布过 Mac 驱动，这台打印机也不支持 AirPrint。 这个项目把它的私有协议逆向出来，做成了一个真正的 macOS 驱动 —— 装个安装包，添加打印机，就能打印。

Canon ships no macOS driver for its GM MegaTank series, and these printers speak no driverless protocol — no AirPrint, no IPP. This is a real CUPS driver built by reverse-engineering the wire format.

安装 Install

sudo installer -pkg CanonGM2080Native-1.0.1.pkg -target /
./add-printer.sh <打印机IP>
手动添加打印机时，「协议」一定要选「HP Jetdirect — 插口」，不要选 IPP。
IPP 恰好是这台打印机唯一不支持的协议，而 macOS 默认就选中它 —— 选错会弹出「目前无法与打印机通信」。「队列」一栏留空。

顺带一提，「HP Jetdirect」只是个历史遗留的名字，并不是 HP 的私有协议： 端口 9100 的标准名称是 PDL Data Streaming，本质上就是一条裸 TCP 连接，各家打印机通用。

功能 Features

  • 打印：多页、双面（含短边装订）、多份
  • 维护：喷嘴检查、清洗、深度清洗、系统清洗、打印头对齐
  • 通过 SNMP 读取墨水余量
  • 通用二进制（Apple Silicon + Intel），不需要 Docker、不含任何佳能代码，MIT 许可

它是怎么做出来的 How it was built

打印机通过 SNMP 自报的设备 ID 就说明了一切：

MFG:Canon;CMD:BJRaster3,NCCe,IVEC;MDL:GM2080 series;CID:CA_IVEC1TYPE2_IJP;

CMD: 是它能解析的格式的完整清单 —— 没有 PDF、没有 PostScript、 没有 PCL、没有 PWG Raster、没有 URF。631 端口关闭，所以 AirPrint 从根上就不可能。

但它真正想要的东西其实很简单：用纯文本 IVEC XML 命令包裹的 PWG Raster， 发到 9100 端口，没有二进制封帧、没有长度前缀、没有校验和。 格式是通过差分分析确定的 —— 在容器里跑佳能自己的 Linux 驱动当作参照， 喂给它已知输入，抓下产出的字节，再逐字节复现。

完整证据、两条已被排除的死路、以及协议里每一处字节差异的解释，都记录在 protocol.md 和 investigation.md。
